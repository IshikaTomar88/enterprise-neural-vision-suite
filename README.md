# 🚨 Enterprise Real-Time Neural Vision, CCTV & MOT Security Suite

An elite, production-grade security and computer vision application built with **Python** and **Streamlit**. Designed for real-world CCTV camera and video file monitoring, dynamic spatial anomaly heatmaps, automated green/red threshold warnings, SMS/Webhook incident dispatch, and password-protected secure vault storage.

---

## 🚀 Key Features

* **Real-World Camera & Video Integration:** Plug in live RTSP security streams, local webcams, or upload video files (`.mp4`, `.avi`) for inspection.
* **Spatial Anomaly Heatmaps:** Dynamic color-graded grid matrices tracking high-density crowds or unauthorized zone breaches.
* **Automated Red/Green Signal Warnings:** Instant visual status feedback that flags dangerous breaches and tracks incident history.
* **Automated Alert Dispatch:** Simulates SMS warnings and webhook triggers when parameters exceed safe thresholds.
* **🧠 Short-Term & Long-Term Memory Manager:** Session-isolated caching paired with long-term encrypted vault storage.
* **🔒 Military-Grade Protection:** Optional SHA-256 password-locked file encryption for official security audits.
